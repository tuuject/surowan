# 内置多服务商网络搜索

这个需求是为了满足 [#35](https://github.com/tuuject/surowan/issues/35) 的 Feature Request。

## 为什么要做？

让模型在不知道具体 URL 时也能先搜索，拿到标题、URL 与摘要，再按需读取网页正文。搜索只负责发现信息，不抓取正文，以减少单次搜索的上下文占用和成本。

## 希望实现什么？

- 增加可控的内置网络搜索能力，沿用现有内部能力的调用、校验和审计方式。
- 支持 Tavily、Brave、Exa、Firecrawl、DeepSeek、SearXNG、You.com，允许用户配置多个搜索引擎。
- 每个搜索引擎都有 LLM 可见的备注，说明搜索哪些网站或内容时建议使用该引擎。
- 允许覆盖服务地址，接入兼容 Tavily 协议的自建或中转服务。
- 每家服务商作为独立插件，依赖网络搜索插件，支持通过插件扩展服务商。
- 管理员可以在面板实时修改搜索配置，无需重启；修改搜索引擎的服务商、密钥等配置时，已发起的请求继续使用发起时的配置，后续请求使用新配置。
- 禁用部分搜索引擎且仍有其他引擎启用时，运行中的 Invocation 若请求已禁用的引擎，通过 steer 提醒模型重新获取搜索引擎列表。
- 关闭整个搜索功能与禁用所有搜索引擎效力相同：立刻停止当前正在进行的 Invocation，接下来的新消息使用重建的 Context 开启新的 Invocation。
- 默认不启用搜索功能。未配置、关闭搜索功能或所有搜索引擎均被禁用时，搜索能力与对应的 Skill 索引对模型不可见。

## 打算怎么做？

### 搜索输入与结果

- 模型通过现有内部能力调用入口发起搜索；需要正文时，再使用网页读取能力。
- 模型参考各搜索引擎的备注，根据要搜索的网站或内容选择本次使用的搜索引擎。
- 返回标题、URL 与摘要。单条摘要最多 600 字符，整段结果最多 24 KiB。
- 内部能力返回正文的硬上限为 30 KiB，超出会被截断；24 KiB 和 30 KiB 均按 UTF-8 字节数计算。
- 查询最多 500 字符，发送前按当前服务商上限静默裁剪：DeepSeek 为 128 字符，Tavily、Brave 为 400 字符，其余为 500 字符。
- 工具描述不写死某家服务商的查询长度上限和默认结果条数，以适应同一个 Invocation 内的配置变更。

### 搜索结果 URL 过滤

- 允许用户配置正则表达式，过滤掉 URL 命中规则的搜索结果，例如 `csdn`。
- 规则输入可使用 textarea，每行一个正则表达式；也可考虑使用一列支持增删的 input，每项一个正则表达式，具体控件形式待定，优先选择 Web 前端实现最简单的方案。
- 规则输入区域下方提供测试文本框，用户可以粘贴 URL，高亮显示被规则命中的 URL，以确认过滤效果。

### 插件分工与扩展

- 网络搜索插件负责搜索能力本体、超时与 Invocation 剩余时间约束、审计、结果展示、错误分类，以及 URL 归一化、摘要截断等共用处理。
- 七家服务商各自提供独立插件，负责本家的请求构造、响应解析与规格。规格包括标识、显示名、默认地址、是否需要密钥、查询长度上限。
- 插件框架支持依赖声明和扩展点。网络搜索插件声明服务商扩展点，各服务商插件向该扩展点提供适配能力；扩展契约需要明确的类型约束。
- 插件只能向其声明依赖的插件所提供的扩展点贡献能力。
- 加载插件时，依赖必须存在，且先于依赖方加载；缺少依赖、顺序错误、循环依赖、向未声明的扩展点贡献、服务商标识重复时都报错。
- 服务商可选范围由已注册插件决定。插件可以声明自身 Skill 的可见条件。

### 配置与校验

| 配置项 | 已明确的规则 |
| --- | --- |
| 搜索功能总开关 | 整段配置可省略，省略即不启用；提供配置时，开关可省略，缺省为启用。关闭时只需配置开关，其余项可省略。 |
| 搜索引擎 | 支持配置多个搜索引擎，各自配置服务商、服务地址、密钥、默认结果条数、超时和备注。 |
| 搜索引擎开关 | 允许单独禁用某个搜索引擎；禁用所有搜索引擎与关闭整个搜索功能效力相同。 |
| 服务商 | 每个搜索引擎都须指定已注册的服务商。 |
| 服务地址 | 各引擎可覆盖服务商默认地址；SearXNG 必须提供地址。 |
| 密钥 | 各引擎通过密钥引用配置；需要密钥的服务商必须提供。SearXNG 不需要且不允许配置密钥，You.com 可省略密钥，使用免费端点。 |
| 默认结果条数 | 各引擎分别设置，范围 1–10，缺省为 5，模型可在单次调用覆盖。SearXNG 不支持该参数，条数由实例默认分页决定。 |
| 单次请求超时 | 各引擎分别设置，范围 5–30 秒，缺省为 15 秒，且不超过 Invocation 剩余时间。 |
| 备注 | 对 LLM 可见，说明搜索哪些网站或内容时建议使用该引擎。 |

- 配置 DeepSeek 搜索时，如果用户已在模型供应商中配置 DeepSeek 官方 endpoint 和 Key，允许选择使用已经配置的 Key，或者另外指定一个 Key。面板提供这两种密钥来源的选择。
- SearXNG 只接入不需要鉴权的实例，服务地址也不接受内嵌凭据。
- 各家的地址与密钥要求，由网络搜索插件根据服务商插件提供的规格统一校验。
- 配置检查、服务启动、热更新应用、面板保存四条路径，都拒绝未注册的服务商和缺失的必填项。校验失败时，当前生效的配置保持不变。

### 按请求固定配置

- 每次搜索执行时读取当前生效的配置。
- 请求开始时，一次性固定本次所选搜索引擎的服务商、服务地址、已解析的密钥、结果条数与超时；整个请求只使用这份配置。查询裁剪也按这份配置对应的服务商执行。
- 搜索进行中修改所选搜索引擎的服务商、更换密钥，在途请求仍使用旧配置完成；同一个 Invocation 的下一次搜索使用新配置。
- 在正在进行的 Invocation，如果模型请求使用了刚刚禁用的搜索引擎，且仍有其他引擎启用，则进行 steer，提醒模型重新获取搜索引擎列表。
- 如果关闭了搜索功能或禁用了所有搜索引擎，则立刻停止当前正在进行的 Invocation，将接下来的新消息使用重建的上下文开启新的 Invocation。
- 请求发起时若搜索已关闭、所有搜索引擎均被禁用或所选搜索引擎已失效，返回明确的失败结果。
- 审计记录本次请求实际使用的搜索引擎与服务商。

### 管理面板

- 提供搜索设置页，支持配置多个搜索引擎及编辑各引擎的备注，支持英文和简体中文。
- 可选服务商从后端读取已注册插件的规格，包括标识、显示名、默认地址与是否需要密钥。
- 读取配置时，只显示密钥是否已配置，不返回明文。
- 保存时检查配置版本，识别版本冲突；新密钥存入密钥库，配置文件只保存密钥引用。关闭搜索或更换密钥后，回收不再被引用的密钥条目。
- 配置原子应用，无需重启。
- 保存操作只接受已登录的面板会话，并校验请求来源；纳入面板允许的管理写操作范围。
- 搜索功能总开关及搜索引擎开关旁提示：关闭整个搜索功能或禁用所有搜索引擎效力相同，都会改变 Skill 索引，立刻停止当前正在进行的 Invocation；所有受影响对话在下一次 Invocation 重建 Context，旧历史不保留，接下来的新消息使用重建的 Context 开启新的 Invocation。
- 总开关启用且至少一个搜索引擎启用时，搜索功能才可用；由不可用恢复为可用时，Skill 索引改变，所有受影响对话在下一次 Invocation 重建 Context，旧历史不保留。
- 禁用部分搜索引擎且仍有其他引擎启用时，运行中的 Invocation 若请求已禁用的引擎，通过 steer 提醒模型重新获取搜索引擎列表。只更换现有搜索引擎的服务商、密钥或搜索参数不会触发 Context 重建。
- 若提供会真实发起搜索的测试操作，须先让用户明确确认，因为每次搜索都会计费。

### 错误与安全边界

- 搜索失败不自动重试。
- 失败分类覆盖：认证失败、额度耗尽、限流、上游不可用、请求被拒，以及重定向被拒、响应过大、超时、Invocation 到期、密钥无法解析、响应无法解析、网络失败。
- 上游状态按以下方式区分：401/403 为认证相关失败；无需密钥的服务商返回 403 时提示“端点拒绝请求，检查 JSON 输出”；402/432/433 为额度耗尽；429 为限流；5xx 为上游不可用；其余 4xx 为请求被拒。
- 密钥不进入审计、日志或模型上下文。
- 拒绝所有重定向，避免密钥随跳转泄露；失败响应体不读取、不回显。
- 响应增量读取，最多 256 KiB。
- 搜索结果明确标为不可信数据，不能作为指令或授权。URL 归一化，防止通过换行伪造结果。

### 验收与文档

- 保留各服务商请求构造、认证、结果归一化（含空结果）、错误分类，以及重定向、URL 注入、密钥解析失败、超时、未配置或搜索不可用时能力与 Skill 索引不可见等验证；服务商相关测试按各自插件组织。
- 验证插件依赖、加载顺序、循环依赖、扩展点贡献与重复服务商标识的错误处理。
- 验证四条配置路径均拒绝未注册的服务商和缺失的必填项。
- 验证多个搜索引擎的备注对 LLM 可见，模型可以选择本次搜索使用的引擎。
- 验证搜索途中修改所选搜索引擎的服务商、更换密钥时，在途请求仍用旧配置完成，同一 Invocation 的后续搜索使用新配置，审计反映实际使用的搜索引擎与服务商。
- 验证仍有其他搜索引擎启用时，模型在运行中的 Invocation 请求刚被禁用的引擎，收到 steer 提醒，重新获取搜索引擎列表。
- 分别验证关闭整个搜索功能、禁用最后一个启用的搜索引擎和一次禁用所有搜索引擎，均立刻停止当前正在进行的 Invocation；接下来的新消息使用重建的 Context 开启新的 Invocation，搜索能力与对应的 Skill 索引不可见。
- 面板验证覆盖配置版本冲突、密钥不回显、无引用密钥回收，并通过端到端测试覆盖新设置页。
- 验证 URL 正则过滤生效，规则输入区域下方的测试文本框能高亮显示粘贴后被规则命中的 URL。
- 更新架构、配置、Agent 流程、管理面板、验证说明及插件契约说明，记录插件依赖、扩展点、按请求固定配置，以及禁用部分引擎与禁用所有引擎的不同运行行为，明确禁用所有引擎与关闭整个搜索功能效力相同；用户扩展指南补充面板配置方式。
