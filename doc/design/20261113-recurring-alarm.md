# 循环闹钟

## 为什么要做？

主动任务被认为是这种 Bot 的标配。例如：

- 每天早上八点发送问候语。
- 每天下午六点收集最近资讯作为简报（借助未来会开发的外部任务委派功能，用 ACP 协议叫第三方 Agent 做）。

## 希望实现什么？

- 管理员可以使用类似 cron 的配置，实现定时在已有的或新建的 Invocation 注入提示词，实现定时任务。

## 打算怎么做？

### 创建

- 只允许管理员自己在 Admin Panel 新建。
- 管理员输入的提示词都是可信的。

### 执行周期

- 可以使用 cron 表记法声明执行周期。
- 也可以使用控件手动添加多条规则：分、时、日、月、星期，都可以选择「每」或「第」。

### 触发

- 到点触发时，与现有的单次闹钟一样：不占每日预算，也不受睡眠时段影响。
