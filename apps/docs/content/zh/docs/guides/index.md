# 从这里开始

塑料碗 Harness（Surowan Harness）是一套人设无关的 Harness 服务端。一个部署实例连接一个 Telegram Bot，把短时间内的消息攒成一批，连同之前的对话上下文交给你选择的模型，由模型决定这一批值不值得开口。Bot 是谁、用什么语气、在哪些群里活跃，都写在人格 Prompt 与配置里，产品本身不预设角色。

## 适合谁

- 想在自己的机器上跑一只 Telegram Bot，用自己的模型 API Key、自己承担费用的人。
- 想亲手写人格、按群微调行为，而不是从角色卡里挑一个的人。
- 愿意读配置、偶尔看审计与日志的人。日常操作大部分能在管理面板完成，但第一次部署仍需要一次服务器 shell。

真实平台目前只有 Telegram。不接 Telegram 时，管理面板与内置的虚拟群聊仍然可用。

## 第一次的顺序

1. 安装并登录面板，见[安装与首次登录](installation.md)。
2. 接入一个能正常回复的 Agent 模型，见[接入和更换模型](models.md)。
3. 写一份人格，先在虚拟群聊里试，见[你的第一个人设](first-persona.md)。
4. 接上 Telegram，在真实群里验证，见[你的第一只 Bot](first-bot.md)。

前两步不能省。没有可用的 Agent 模型，Bot 收到消息也不会开始运行。

:::tip 想直接接 Telegram？
模型配好以后，可以跳过虚拟群聊，直接按[你的第一只 Bot](first-bot.md)接入。先试用再上群只是把可能的出错点分开，因为虚拟群聊里没有群权限、消息可见性和白名单这些问题。
:::

## 只需要先懂这些

| 概念 | 一句话 |
| --- | --- |
| 实例 | 一次部署：进程、配置文件和 data 目录。一个实例只连接一个 Telegram Bot。 |
| Bot | 你在 Telegram 里对话的那个账号。Token 可以先不填，那时只跑管理面板与虚拟群聊。 |
| 人格 | 全局人格文件，加上每个 Chat 的附加指令。它决定身份和语气，不授予任何权限。 |
| 供应商与模型 | 供应商是连接方式与密钥，模型是显式启用的条目。有三项工作角色：主模型、图片识别、工具模型。 |
| 密钥 | 存在 `key.json`（Keychain）里的命名条目；配置文件只写 `{ "jar": "名字" }` 这样的引用。 |
| Chat 与 Topic | 允许 Bot 活动的范围。Topic 共用该 Chat 的模型、记忆与参与设置，但对话上下文互相隔离。 |
| 一次运行 | 把一批消息与当前上下文交给模型的一次执行。模型可以发言，也可以保持沉默。 |
| 上下文与记忆 | 连续对话（Context）、Memo、群聊记忆、辞典是四件不同的事，别混着用。 |
| 提醒与循环闹钟 | 对话里的一次性提醒由 Bot 自己建；循环闹钟是你在面板里设定的周期任务。 |
| 入场闸门 | 可选的小模型前置筛选：先判断这一批值不值得交给主模型，再决定是否拦截。 |
