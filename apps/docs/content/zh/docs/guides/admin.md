# 管理面板、密钥与访问安全

管理面板与 `serve` 同进程启动，是你查看运行、改配置、管密钥的地方。它不是本静态文档站，也不应该直接暴露在公网。

## 1. 打开它

`admin` 段是必填配置；`enabled` 省略即为 `true`，只有明确写 `false` 才不启动面板。

```jsonc
{
  "admin": {
    "host": "127.0.0.1",
    "port": 8787,
    "session_ttl_hours": 24
  }
}
```

`admin.*` 的所有字段都需要重启才生效，它们的类型与默认值见 [`admin` 字段参考](../configuration/fields-admin.md)。Docker 部署里容器内要监听 `0.0.0.0`，但端口发布只到本机回环：

```yaml
    ports:
      - "127.0.0.1:8787:8787"
```

启动日志里的 `admin_started` 会给出实际的 host 与 port；打不开时先确认这一行，再看[排查启动失败和不回复](troubleshooting.md)。

## 2. 任务地图

导航分七组，共三十二页。按你要做的事找：

| 组 | 页面 | 用来做什么 |
| --- | --- | --- |
| **监控** | 概览、警告 | 一眼看运行量、在线状态与需要处理的警告 |
| **活动** | 运行记录、批改、上下文、消息、虚拟群聊 | 追一次运行、标注它哪里不对、翻原始消息 |
| **数据** | 记忆、群聊记忆、辞典、提醒、循环闹钟 | 管理 Bot 记住的东西与定时任务 |
| **媒体** | 图片生成、生图记录、生图素材、图片设置 | 生图工作台、历史、参考素材与开关 |
| **机器人** | 模型、供应商、提示词、运行参数、入场闸门、MCP 服务器、网络搜索 | 决定 Bot 用哪个模型、说什么、花多少 |
| **Telegram** | Telegram、会话、机器人管理员、贴纸集 | 接上 Telegram 并划定它的活动范围 |
| **系统** | API 密钥、密钥、开发者、设置、面板偏好 | 凭据、调试开关与本浏览器的显示设置 |

日常最常用的是 **概览**、**运行记录**、**会话** 与 **设置**；其余页面按需进入。

## 3. 远程访问

面板本身只提供明文 HTTP，安全边界由你负责：

- 本机访问：保持 `admin.host` 为 `127.0.0.1`，只通过 SSH 隧道（`ssh -L 8787:127.0.0.1:8787 …`）或本机浏览器打开。
- 远程访问：放在你自己管理的 TLS 反向代理后面，并把 `admin.public_url` 写成浏览器实际访问的那个 origin，例如 `https://panel.example.com`。
- `public_url` 必须是规范的 HTTPS origin：不带用户名、密码、路径、查询参数或 `#` 片段，也不能是 IP 地址（本机开发允许 `http://localhost`）。它是 WebAuthn 的 RP，换了域名就要重新注册通行密钥。

配了 `public_url` 之后，所有写操作的 `Origin` 必须正好等于它；否则返回 `bad_origin`。没配时则要求请求来源的主机与访问地址一致。这意味着**从哪个地址打开，就用那个地址操作**，不要一会儿回环一会儿域名。

## 4. 登录方式：没有网页建号

面板没有「创建管理员」的网页表单，新实例的登录页和已在用的实例完全一样（用户名、密码、使用一次性码登录三个入口），这样别人无法从页面判断哪台机器还没人管。

两条进入方式：

1. **服务器一次性码**（`pairing create --web`）：需要能 SSH 到服务器，不用停服务，且会顺带在空实例上创建没有密码的 `admin`。
2. **离线建号**（`admin-account`）：需要停服务，适合一次性码也不可用、或者要重置密码的场合。

## 5. 一次性码登录

```bash
node src/cli.ts pairing create --config /path/to/config.jsonc --web

# Docker 部署
docker compose exec -u surowan plasticwan node /app/src/cli.ts pairing create --config /config/config.jsonc --web
```

输出 JSON 里的 `code` 是 `pwp_` 开头的码，`pairing.expires_at` 是过期时间（默认 5 分钟，`--ttl-seconds` 可设 60–3600 秒）。打开面板，点 **使用一次性码登录**，粘贴后点 **登录**。

- 每个码只能使用一次，过期或被 `pairing cancel` 取消后失效；未用的码用 `pairing list` 查。
- 登录码与给编码 Agent 的配对码是两套：登录页会拒绝 Agent 配对码，反过来 `surowan-utils auth pair` 也领不了登录码。
- 使用官方镜像时，登录页会直接显示上面这条 Docker 命令并带复制按钮；自建镜像只显示通用提示。
- 登录本身不改密码，也不注销已有的 Session。

## 6. 密码、锁定与通行密钥

- 用户名 3–32 个字符，可用字母、数字、点、下划线、连字符；密码 12–200 个字符。
- 密码失败按**TCP 对端地址**计数：同一地址连续 10 次失败后，该地址的密码登录锁定 15 分钟（返回 `too_many_attempts`）。这里刻意不看 `X-Forwarded-For`——请求方可以伪造它换一个计数桶。代价是放在反向代理后面时所有访客共享代理地址：任何人失败 10 次，会同时锁住管理员的密码登录。所以代理部署建议配 `public_url` 并注册通行密钥。
- 通行密钥只在配置了 `admin.public_url` 后可用，并且必须在安全上下文里（HTTPS，或 `localhost` 的 HTTP）。可以注册多个，例如办公电脑与手机各一个。
- 账号没有密码时，**删除最后一个通行密钥**的按钮会被禁用，界面提示先在 **管理员凭据** 里设置密码，避免把自己锁在门外。
- 反过来，**删除密码**（转为仅通行密钥登录）要求当前网站已注册至少一个通行密钥；删除后会注销全部旧 Session，并给当前浏览器签发一个新的。
- 更换域名后旧通行密钥仍在列表中，但会标记为无法在此登录；删除 `public_url` 只是关闭通行密钥功能，不会删除已注册的凭据。

## 7. 恢复：改密码与离线建号

只是要临时登录一次，用上面的一次性码最快，也不用停服务。

密码忘了、通行密钥也丢了，才用 `admin-account`：

1. **先停服务**：它直接改数据库，运行中的实例会拒绝执行。
2. 交互式执行，终端会隐藏输入并让你重复一次：

```bash
docker compose run --rm plasticwan admin-account --config /config/config.jsonc --username <name>
```

3. 非交互环境用 `--password-stdin` 从管道读密码，不要写在命令行参数里（会留在 shell 历史与进程列表）。

每次执行都会注销该账号的全部登录 Session；Passkey 默认保留，加 `--revoke-passkeys` 才一并删除；API 密钥不受影响。表里只有一个管理员时它会改名并重置，一个都没有时会创建，多于一个则直接报错退出。

## 8. 密钥页（Keychain）

配置里的 Token、API Key 都不写明文：文件里写 `{ "jar": "名字" }`，明文放在配置文件同目录的 `key.json` 里。**密钥** 页管理这些条目：

- 列表显示 **名字**、**创建时间** 与 **被使用于**（从配置文件反推的引用路径）。运行中的配置仍在使用、但文件里已经改掉的条目会标为「仅运行中的配置」；两边都不引用的标为「未使用」。
- **新建条目**：填名字（1–64 个字母、数字、`_` 或 `-`）与值。可以先建一把暂时没人用的密钥，再去使用处引用。
- **轮换**：在原条目上换值并保留创建时间，成功后立即触发一次应用，所有使用该条目的连接（含 MCP Server）一起换新；正在运行的会话继续用它启动时的快照。
- **删除** 只允许没有被任何地方引用的条目；**清理孤儿** 会列出将被删除的名字，服务端只删除确认时仍是孤儿的条目。
- 配置文件无法解析时，删除与轮换都会被拒绝，而不是按残缺的引用集合冒险。
- **任何地方都不显示密钥的值**：页面、接口、列表都只出现名字。`/api/keychain*` 是仅面板 Session 可用的内部接口，API 密钥与配对客户端都调不到。

## 9. API 密钥

**API 密钥** 页为脚本、评估工具与 MCP Server 签发密钥：新建时四选一模式（只读、读 + 改、读 + 耗、全部），可以改模式、轮换或撤销，明文只在创建弹窗出现一次。账号与凭据整类排除在这些密钥之外——无论什么模式，都不能改管理员密码、管理通行密钥或管理 API 密钥本身。想吃透权限差异与用法，见[让你的本地 Agent 帮你调整塑料碗](agent-assisted.md)与[HTTP 公共约定](../developer/http/index.md)。

## 10. 运行记录：自动刷新与自动滚动

**运行记录** 列表与详情默认**自动刷新**（开关在列表顶部与详情底部），正在跑的 Invocation 会在原位置不断出现新的工具调用、模型调用与发送状态。详情页底部还有 **自动滚动到底部**，默认关闭：打开后每有新进展页面就滚到最底。两个选择都存在当前浏览器里，互不影响。

## 11. 界面语言与面板偏好

面板提供四种界面语言：English、中文、Deutsch、العربية。顶栏的语言菜单按各语言自己的名字列出，当前语言带勾选；**面板偏好** 页也能选。切换立即生效，不需要刷新，选择写入浏览器（`admin-language`）；没手动选过时跟随浏览器语言，`zh`、`de`、`ar` 开头分别对应中文、德语、阿拉伯语，其余为英文。

阿拉伯语是真正的从右到左布局：导航在右侧，整页方向翻转；模型 ID、API 密钥、URL、时间戳等技术字符串仍按从左到右显示，复制出来的内容与存储值一致。

**面板偏好** 只影响当前浏览器：主题与语言，不写入配置文件，其他浏览器与管理员的设置互不影响。后端返回的错误消息始终按服务端原文显示。

## 12. 安全清单

- 面板端口不直接暴露到公网；远程访问走 TLS 反向代理，并配 `admin.public_url`。
- 至少保留两种登录方式：密码 + 通行密钥，或至少把一次性码当成应急入口。
- 定期看 **密钥** 页的孤儿条目和 **警告** 页；被替换下来的旧密钥不会自动消失。
- 不要把面板 Session Cookie、API 密钥或 `key.json` 复制到聊天、Issue 或截图里。
