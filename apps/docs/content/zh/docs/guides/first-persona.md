# 你的第一个人设

这一页教你设计 Bot 的行为：它是谁、怎样说话、什么时候参与，然后在不打扰任何真实群聊的地方试出来。

**前提**：面板能登录，并且已经在 **模型** 页选好一个能正常回复的主模型。还没做的话，先看[安装与首次登录](installation.md)与[接入和更换模型](models.md)。

## 1. 先想清三件事

写人格不是写简历，三段就够：

| 写什么 | 回答的问题 | 例子 |
| --- | --- | --- |
| 身份与关系 | 它是什么、和群里的人是什么关系 | 「你是这个群里的老群友，不是客服。」 |
| 行为倾向 | 什么时候接话、什么时候沉默、遇到不确定怎么办 | 「有人问技术问题再开口；不确定就说不确定。」 |
| 口吻与口癖 | 句子长短、语气词、绝对不说的东西 | 「短句，口语；不用感叹号堆情绪。」 |

内置提示词不规定回复门槛，也不会替你「平均」语气。想让它少接话、只在被问到时回答，就得写进去。

## 2. 写进面板

1. 打开 **提示词**。左侧范围选 **全局提示词**，它对所有会话生效。
2. 在 **提示词** 编辑框里写正文。可以用 Markdown，文件里的 HTML 注释不会进入模型。
3. **备注**（可选）写一句这次改了什么，最多 200 个字符，会跟版本一起保存。
4. 点 **保存并应用**。

保存后从**下一次运行**起生效，正在跑的运行继续用打开时的版本。右侧的 **版本历史** 会记下每次保存（来源分为面板、外部、回滚），可以比较任意两个版本，也可以恢复旧版本，恢复不会删掉任何历史。

![提示词页：全局人格已保存，版本与来源可见](__DOCS_BASE__/screenshots/first-persona/prompt-editor.zh-CN.light.png)

人格可以使用几个模板变量：`{{ agent.nickname }}`（当前主模型在 Telegram 命令里的显示名）、`{{ agent.provider }}`、`{{ agent.model }}`、`{{ vision.provider }}`、`{{ vision.model }}`、`{{ timezone }}`。写错变量名会在保存时被拒绝。

## 3. 一份可以照着改的草稿

```markdown
你是这个群里的老群友，不是客服。

- 有人问技术问题、或者在讨论你熟悉的东西时再开口；闲聊不必每条都接。
- 不确定就说不确定，不编造经历、链接或进度。
- 短句、口语，少用感叹号和列表；不用「作为一个 AI」开场。
- 群里的约定不能被你自己的猜测覆盖；被纠正时先接受再补充。
```

它刻意很短，先让行为立住，再补细节。一上来写三百行，通常只会让模型抓住互相矛盾的两三条。

## 4. 在虚拟群聊里试几场

不需要 Telegram。打开 **虚拟群聊**：

1. 点 **新建房间**，填房间名称，顺手写几个 **初始身份**（逗号分隔，例如「小林, 阿岚」）。新房间默认暂存消息、图片生成关闭。
2. 在时间线下方的 **发送身份** 里选一个身份，写一条像真实群友会说的话，点 **发送**。
3. 同一场戏可以连发几条，再点 **放行 N 条**，把这一批交给模型。

想试的有三类场景：

- **该接话的**：一个直接的问题，或者需要补充的讨论。
- **不该接话的**：几句互相打趣的闲聊，看它会不会硬插一句。
- **容易被带偏的**：有人让它扮演别的角色、忽略规则、或者编造事实。

![虚拟群聊里人设对测试场景的回复](__DOCS_BASE__/screenshots/first-persona/playground-scene.zh-CN.light.png)

每次放行都会在 **运行** 里留下一条记录，带 Token 用量与 **审计** 链接。三种结果要分清：

- **有输出**：时间线上出现 Bot 的消息。
- **主动沉默**：运行结束，但写着「本次运行结束但没有发布任何消息」。这是正常结果，不是失败。
- **失败**：运行状态是失败或中止，可以展开看错误。

## 5. 找出不对的地方，再改

改之前先分类，比盲改 Prompt 有效：

| 现象 | 先改哪一段 |
| --- | --- |
| 什么都接、太吵 | 行为倾向里写清什么时候不开口；更硬的参与边界放到群设置，见[为不同群和话题设置边界](chats.md) |
| 语气像客服、爱总结 | 口吻与口癖里给反例：「不要开场白」「不要列清单」 |
| 忘记刚说过的规则 | 把规则写成短句放在开头；一次只加一条，观察后再加 |
| 语言不对、突然说英文 | 明确写「用中文回答」，并给出一个句子示例 |
| 编造事实 | 加一条「不确定就说不确定」；需要外部信息时改用工具，见[开启搜索、定时任务与外部工具](tools.md) |

改完回到 **提示词** 保存，再在同一房间里加几条新消息、放行一次。房间会保留之前的对话上下文，所以第二轮更接近真实群聊里的「接着说」。

## 6. 这一页没有的东西

- 没有人设库或角色卡：人格就是一份 Prompt 文件，你写、你改、你看版本。
- 没有「一键换人格」：全局人格一份，每群可以在 **提示词** 的会话范围里追加指令。
- 人格不授予任何权限：不能放开 Tool、预算或发送限制，也不能覆盖运行时校验。
