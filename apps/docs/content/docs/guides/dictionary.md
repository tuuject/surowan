# 管理全局与群组辞典

辞典用于解释昵称、缩写、黑话和内部梗。全局辞典对所有会话可读；群组辞典属于一个 Chat，同群的 Forum Topic 共用词条，但各 Topic 的 Conversation Context 仍独立。其他群的词条不会进入当前群的查询结果或自动注入。私聊只能读取全局词条。

辞典与 [Memo Pad](./memory.md) 分开维护：词条描述一个表达的含义，Memo Pad 保存事实、材料或偏好。辞典解释属于数据，不能授予工具权限或替代人格 Prompt。

## 创建和修改词条

1. 登录 Admin Panel，进入 **Dictionary**。
2. 选择全局辞典或一个群组。
3. 新建词条，填写主词名称（Term）、解释（Definition）和可选的别名（Aliases）；别名每行一项，逗号和竖线是别名原文，不是分隔符。
4. 设置启用状态并保存。

主词和解释不能留空。同一词条内重复的别名会去重；不同词条可以使用相同主词或别名。编辑和删除都按词条 ID 定位，因此不会连带修改其他同名词条。删除需要确认。

群聊 Agent 可以查询全局与本群的启用词条，并创建、修改本群词条；不能写全局词条、修改其他群词条或把群词条提升为全局词条。管理员可以在面板维护两种作用域。

## 匹配和自动注入

匹配区分大小写，按字面字符串进行，但忽略汉字与英文字母或数字之间的水平空白：例如 `AB钙` 和 `AB 钙` 都能查询或触发同一词条。英文词之间的空格和换行不忽略，保存的词条与别名仍保留原文。主词和别名都可以在较长消息中命中，例如别名“碗”会匹配“今天碗怎么不说话了？”。不进行语义搜索、拼写纠错或分词扩展。多个词条同时命中时保留多个解释，全局词条不会覆盖群组词条。

可以设置全局注入策略，并按 Chat 覆盖：

| 模式 | 行为 |
| --- | --- |
| Off | 不自动注入；Agent 仍可以主动查询辞典 |
| On Demand（默认） | 命中时注入相关词条 |
| Aggressive | 预加载全局与本群的有效词条，减少主动查询需求 |

同一版本的词条仍在当前有效 Context 中时，不会重复注入。Context 滚动丢弃该词条后，再次命中可以重新注入；词条更新后可以注入新版本。新 Invocation 继承实际保留的 Context，不会因为一次运行结束就重置去重。

辞典没有独立 Token 预算，但仍受模型上下文窗口和现有 Context 管理限制；预加载不能保证大型辞典一次全部进入上下文。停用词条后，后续查询和自动注入不再使用它；已经写入历史 Context 的旧解释不会因此自动从历史中抹去。

## 查看冲突并融合

两个不同词条的主词或别名在匹配规范化后相同时，面板会提示潜在冲突，例如 `AB钙` 与 `AB 钙`。检查包括主词与主词、主词与别名、别名与别名，以及全局与所选群的交叉冲突。冲突不会阻止保存、查询或注入，可以保留多种含义。

需要整理时：

1. 选择两个或更多词条，请求 AI 生成融合建议。
2. 审阅并修改建议的主词、解释和别名。
3. 明确选择融合结果保存到全局还是指定群组。
4. 明确选择是否保留来源词条，再确认保存。

生成建议会调用 **Tool Model**，可能产生模型费用。建议本身不会修改数据库或删除来源词条。若来源在审阅期间被修改，需要刷新后重新检查，不能用旧建议覆盖最新数据。

在 **Models** 中可以为辅助任务选择 Tool Model 及 thinking 级别；未单独配置时继承全局 Agent 模型。融合失败时，仍可使用普通管理、查询、自动注入和手动整理。

## 批量导入与导出

支持 CSV 和 JSONL。导入时选择目标作用域、上传文件、查看解析预览及冲突，确认后批量创建词条。导入不会因为同名而覆盖已有词条。

CSV 的核心列为 `term`、`definition`、`aliases`，可带 `enabled`。多个别名在一个单元格中用 `|` 分隔；别名中的竖线写为 `\|`，反斜杠写为 `\\`。包含逗号、引号或换行的单元格按 CSV 规则加引号，其中的引号写两次。例如：

```csv
term,definition,aliases,enabled
塑料碗,群内对 Bot 的昵称,碗|塑料,true
```

JSONL 每行一个 JSON 对象，别名直接写数组：

```jsonl
{"term":"塑料碗","definition":"群内对 Bot 的昵称","aliases":["碗","塑料"],"enabled":true}
```

导出所选作用域后，可用相同格式重新导入。重新导入会创建新词条，因此导入自己的导出文件也可能产生重复项；先检查预览。导出文件可能包含群内术语和解释，分享前应核对内容。
