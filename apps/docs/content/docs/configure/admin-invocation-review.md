# Invocation 批改与导出

当机器人在群聊或私聊里出现「回复太长」「不该接话」「选错贴纸」或「多此一举地调用工具」等问题时，管理员可以在查看审计记录的同时逐条写下批改意见，跨多次 Invocation 汇总后导出一份自带完整提示词的 Markdown 文件，直接交给已连接 `surowan-utils` CLI（配合 `surowan-utils` Skill）或 [Surowan MCP Server](mcp-server.md) 的本地通用 Coding Agent（如 Claude Code、Codex）协助诊断和调优。

## 浏览器本地保存与隐私边界

- **仅保存在当前浏览器**：批改草稿保存在当前浏览器的 `localStorage`（键名 `surowan-admin-review`，版本 `1`）中，**永远不会上传到 Surowan 服务器**，也不写入数据库或配置文件。若浏览器禁止本地存储或空间已满，面板会弹出提示并将批改内容保留在当前标签页内存中，直到关闭该标签页。
- **跨标签页实时同步**：同时打开多个 Invocation 详情页与「批改」汇总页时，任一标签页保存、修改或删除意见后，其余标签页会自动同步，不会互相覆盖。
- **退出登录不丢失**：退出面板登录不会清除浏览器中的批改草稿；只有在确认导出（复制或下载）或手动点击「清空草稿」后才会清空。

## 在运行详情页添加批改意见

打开任一运行详情页（`/invocations/:id`）：

1. **整体评价（Overall comment）**：在摘要卡片下方、标签页上方的「批改笔记」面板中，点击 **添加整体评价** 可记录对本次运行的整体看法；面板同时显示本次运行的批改条数、草稿中包含的运行总数，以及前往汇总页的 **打开批改草稿** 链接。
2. **时间线事件批改**：在默认的 **概览（Overview）** 时间线上，除生命周期节点（入队、开始、结束）外的每张事件卡片——包括新到/历史消息（`context_message`）、模型调用（`model_call`）、工具调用（`tool_call`，含 `send` 发言）与助手私有文本/工具结果/发送提醒（`agent_message`）——底部都提供 **添加批改意见** 按钮。
3. **编辑与删除**：点击按钮展开内联输入框，输入意见后点击 **保存**（或按 `Ctrl+Enter` / `Cmd+Enter`）即可保存；已保存的意见会在卡片下方高亮展示，可随时点击 **编辑** 或 **删除**。将内容清空后保存同样会删除该条意见；当某次运行既没有事件意见也没有整体评价时，会自动从草稿中移除。

每条意见、整体评价与改进目标最多支持 4,000 个字符；保存事件意见时会自动截取最多 280 个字符的事件短摘录，方便在汇总页与导出文件中对照上下文。

## 在「批改」页汇总与配置导出

从左侧导航 **活动 → 批改**（`/reviews`）进入汇总页：

- **选择导出用途（Purpose）**：
  - **调优此机器人（Tune this bot）**：面向机器人管理员。导出的提示词会引导外部 Agent 对照审计记录排查全局人格 Prompt、按群指令、Harness 参数、模型/思考强度或辞典与记忆，并在你逐项确认后协助修改配置。
  - **开发者反馈（Developer feedback）**：面向 Surowan 开发者。导出的提示词要求外部 Agent 不修改正在运行的机器人配置，而是定位内置系统提示词、工具定义/Schema 或运行时行为中的设计缺陷，按影响程度输出诊断报告。
- **填写改进目标（Goal）**：选填，描述你希望整体改进的方向（例如「群聊接话更简短，不要复读群友原话」），会一并写入导出的提示词。
- **逐项整理与预览**：页面按运行创建时间从早到晚列出所有已批改的 Invocation 及其时间线顺序的事件意见，支持原地编辑、删除单条意见或将整次运行移出草稿；展开 **预览 Markdown** 可在导出前查看完整生成内容（展开预览不会清空草稿）。

## 导出 Markdown 并交给 Coding Agent

汇总页右上角提供 **下载 Markdown**（默认文件名 `surowan-review-YYYYMMDD-HHmmss.md`）与 **复制 Markdown** 两个导出动作：

1. **确认导出并清空草稿**：点击任一导出按钮都会先弹出确认框。确认导出后（复制模式下须等待写入剪贴板成功；若剪贴板写入失败，或导出期间其他标签页新增了批改改动，则会保留草稿并弹出提示），当前浏览器中的批改草稿会被自动清空。**管理面板目前不支持将导出的文件重新导入**，请妥善保存下载的 Markdown 文件或粘贴后的内容。
2. **末尾结构化 JSON 尾块**：导出的 Markdown 文档末尾附有 `## Review data (JSON)` 代码块（`format: "surowan.invocation-review"`、`version: 1`），保留全部批改意见与摘录的机器可读副本，供外部 Agent 作为结构化输入读取，并为未来版本的面板重新导入预留格式。
3. **交给外部 Agent 执行**：将导出的 Markdown 文件或剪贴板内容发送给已配置好 `surowan-utils` CLI 或 [Surowan MCP Server](mcp-server.md) 的 Claude Code / Codex：
   - Agent 会先执行只读连通检查（`surowan-utils doctor --json` 或 `surowan_key_show`），再拉取对应 Invocation 的完整审计记录与当前生效的 Prompt。
   - 聊天消息、短摘录、模型输出与工具参数在提示词中被严格声明为不可信数据，只有你的批改意见代表真实意图。
   - 涉及修改 Prompt/配置或触发计费重放（[Invocation 重放](admin-invocation-replay.md)）时，Agent 必须先给出具体方案并取得你的明确授权。
